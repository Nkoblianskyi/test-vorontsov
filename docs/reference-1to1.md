# Reference 1:1

Маршрут: `/templates/[id]/reference`. Код: `src/features/template-editor/ui/reference/`, лист — `src/entities/invoice/ui/classic-document.*`.

## Как снимались размеры

1. **Цвета** взяты попиксельно из скриншота референса (1280 × 724) через `System.Drawing.Bitmap.GetPixel`. В местах со сглаженным текстом брался самый тёмный пиксель области.
2. **Геометрия**: сканировались строки и столбцы пикселей на границах элементов (линии, рамки, кнопки), так находились точные координаты.
3. **Сверка**: в реализации координаты элементов измерены через `getBoundingClientRect()` в окне 1280 × 724 и сравнены с референсом (таблица ниже).

Известные расхождения:

- **Скроллбар.** Референс снят с overlay-скроллбаром macOS. Здесь у области превью свой скруглённый серый скроллбар 8 px с зарезервированным местом (`scrollbar-gutter: stable`). Правый отступ уменьшен на те же 8 px, поэтому лист ровно 691 px при любой высоте контента.
- **Шрифт**: референс снят на macOS (SF Pro). Используется тот же системный стек `-apple-system, BlinkMacSystemFont, "Segoe UI", …`, поэтому на macOS шрифт совпадёт, а на Windows будет Segoe UI.
- **Данные на листе**: вместо «Bigcapital» — вымышленная компания той же формы: название прописными, адрес, телефон. Суммы в референсе не сходятся (subtotal 630 при строке на 1000), в реализации они считаются честно: 1000 + 4.7 % + 7 % − 100 = 1017.00.
- **Даты на листе** — сегодняшние: превью показывает, как будет выглядеть счёт, выставленный сейчас.
- **Невидимые на скриншоте части**: вкладка Content, выпадающий список Date Format (меню в стиле Blueprint вместо системного), диалоги «Payment methods» и «Discard changes?». Они спроектированы в той же системе (system UI, скругления 3–4 px, синий primary, диалог в стиле Blueprint).

## Что делает Secondary Color

На листе референса дополнительный цвет не виден. В реализации у него своя роль:

- на Classic-листе им окрашен блок **Payment details**, который появляется, когда в «Accept payment methods» включён хотя бы один способ;
- на Swiss-листе ещё и плашка **Balance Due**.

В стандартном шаблоне способы оплаты выключены, поэтому по умолчанию лист совпадает с референсом.
